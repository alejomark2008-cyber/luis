# BeautyBodega

Demo de tienda multimarca de maquillaje y skincare para una bodega del centro de Bogotá.

## Incluye
- Inicio con banner principal.
- Categorías clickeables: Rostro, Ojos, Labios y Skincare.
- Marcas clickeables: cada marca abre su propio catálogo.
- Catálogo general.
- Filtros por categoría, marca y precio.
- Búsqueda por producto, marca o categoría.
- Ordenamiento por precio/nombre.
- Carrito de demostración.
- Botón de WhatsApp y teléfono.
- Sección de ubicación.
- Diseño responsive para celular.

## Importante antes de publicar
Los productos, precios, teléfono, enlaces, fotografías y dirección usados en esta demo son ejemplos. Deben reemplazarse por los datos reales del negocio.
